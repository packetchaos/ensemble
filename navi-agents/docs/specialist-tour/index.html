Quick start for new users

How to read a specialist page

Every specialist (the hounds) uses the same page layout, from CISA KEV to Certificates to Exposure Score. Learn it once and you can use all 43.

Your first run, in five steps

  1. Open a specialistFrom the home page or the sidebar. Nothing runs until you ask.
  2. Choose what to coverThe whole estate, or one tag such as a business unit.
  3. Press ▶ RunApprove any public catalog download it asks for.
  4. Read At a glanceClick any number to see the assets behind it.
  5. Tag what mattersConfirm, then watch Done so far and the Tagging log.

Read-only until you say so

Opening or running a specialist only reads navi.db, the local copy of your Tenable data. Nothing changes in Tenable until you press a 🏷️ button and confirm.

Every number has evidence

Findings come from SQL and rules, not an AI model. Click any number to see exactly which assets or findings it counts.

Tagging, step by step

Tagging writes to your Tenable tenant, so every 🏷️ button follows the same five steps.

  1. PreviewThe button names the tag and how many assets it will touch.
  2. ConfirmYou agree to that exact tag and count.
  3. QueueThe job joins the tag queue and runs at a safe pace.
  4. TrackFollow it in the Tagging log; Done so far updates.
  5. SyncUpdate navi.db to see the tags on assets here.

If the button says writes are off

Writes are switched off in Settings by default, and the job is blocked. Ask whoever runs the console to turn writes on. Writes also only work from a browser on the console's own machine.

Tag views stay inside the tag

When the page is filtered to one tag, a tag write only touches assets carrying that tag. The confirmation says so.

When will I see it?

Tags reach Tenable within about 30 minutes. They show on this page after the next navi.db update; until then Done so far counts them as awaiting navi sync.

Tags feed everything else

Other specialists and Tenable One read the tags you write, so one specialist's work improves the rest.

Good habits

Get more out of every run

Start from fresh data

Every specialist reads navi.db. Update it (Settings, or on a schedule) before a review, then press ↻ Re-run on pages you restored.

Follow the evidence

Before acting on a number, click it. The list behind it is the real asset set you would be tagging or reporting.

Try tags in a test run

Turn on Settings → Test run, tag, check the result in Tenable, then clean up with Tag Removal before tagging for real.

Let the Ensemble run overnight

Schedule Run the Ensemble in Automation Station so every page is ready when the team logs in.

Review by owner

Use the Tag filter to open a team's tag. Every number on the page then covers only their assets.

Set the crown-jewel line once

Settings → Crown jewels decides which ACR counts as a crown jewel (8 by default). Every specialist follows it.
