AGENT GROUP SYNC
Coverage
“Turn your agent groups into tags the whole platform can use.”

The Problem

Your Tenable agent groups already describe how the estate is organized — by site, team or role — but agent groups can't be used everywhere tags can. Scans, dashboards, exports and every specialist work from tags, so that structure stays locked inside agent management.

What It Does

Agent Group Sync lists your Tenable agent groups live and tags every asset in each group Agent Group : <group name>, matching Tenable's own membership. Pick groups three ways: type a list of names, tick them in a list, or tag every group at once.

At a glance

Key Capabilities

  • Live from Tenable — agent groups pulled live through navi each time, not a stale copy.
  • Three ways to tag — a typed list of group names, a checkbox per group, or every group at once.
  • Exact membership — navi tags the assets in each group directly, so the tag matches Tenable's own membership.
  • One tag per group — Agent Group : <name>, consistent across the estate and usable in scans, dashboards and exports.

How It Works

Agent Group Sync reads agent groups live through navi and tags with navi enrich tag --c "Agent Group" --v <name> --group <name> — one write per group, behind the write gate and a confirm, recorded in the Tagging log.

Who It's For

Security operations teams who own the tag estate, and anyone who wants scans and reports scoped by how agents are actually deployed.

Works Better With

Group tags give Ownership, Criticality Calibration and SLA Tracker a ready-made way to segment the estate. Automation Station keeps the group tags current on its schedule, and Tag Removal clears any that no longer belong.
