“Write the policy once, arm it when ready — the Ensemble keeps it.”

The Problem

Tags and ACR go stale the moment the estate changes. The Ensemble can find and propose all day, but if a human has to approve every tag on every cycle, upkeep stops the first busy week — and automation nobody can review is automation nobody trusts.

What It Does

Automation turns your tagging history and a plain-English policy into a workflow: which specialists tag, with what logic, which ACR changes to make, which stale tags to clear first, and how often to run. It always shows the plan first; only when you arm it does the loop execute — every few hours, behind the same write gate as everything else.

At a glance

Key Capabilities

  • Start from what you did — build the contract from the Tagging log (or an exported tag-log CSV): the specialists you used and the ACR changes you made become the starting policy.
  • Per-specialist policy — 19 tagging specialists, each on or off with plain-English logic; without a policy a specialist proposes its riskiest top 50.
  • ACR rules in plain English — describe a calibration and Automation writes the rule; optionally protect the changed assets with NO : UPDATE.
  • Tag Removal removal phase — clear the tags you list at the top of a cycle, pause for Tenable to catch up, then re-tag — without deleting the tags themselves.
  • Plan first, armed to act — disarmed, the loop only plans; armed (with writes enabled) it runs on a schedule, every 4 hours by default. A one-off cycle runs only when you confirm it.
  • Each cycle checked and reported — a QA pass on what landed, the loop log, Alerts's checks, and a run-summary email through Notify & Reports.
  • Escape hatch — export the plan as a runnable navi script for when writes must run somewhere else.

How It Works

Each cycle can kick off navi update assets and vulns in the background, builds the plan from each specialist's own discovery and tag scheme (the same tags a person would apply from that specialist's page), then — only if armed — runs it through the background tag queue. Contracts can be saved and loaded as JSON files.

Who It's For

Vulnerability management program owners who need upkeep to survive a busy quarter, and automation engineers who want autonomy an auditor can follow.

Works Better With

Automation orchestrates the tagging specialists — Laelaps, Pythia, Certania, Charon, Linnaeus, Fenrir, Exposure Score, Ownership and the rest — plus Criticality Calibration's ACR rules and Tag Removal's removals. Alerts's checks and Notify & Reports's summary ride along on every cycle.

Why It's Different

  • Same tags as a human — each specialist's adapter mirrors its own tag button — no separate automation scheme.
  • Nothing on its own — the loop runs only when armed, a one-off cycle only when you confirm it — both behind the write gate.
  • Portable — save, load or export the contract — your policy outlives the session.
