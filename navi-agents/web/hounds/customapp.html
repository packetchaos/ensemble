CUSTOM APP DISCOVERY
Asset Truth
“Find the software your inventory missed — and give it a name.”

The Problem

Every estate runs software no package inventory admits to — internal apps, custom builds, tools copied onto a server by hand. They leave traces in web routes and file paths, but nobody names them, so nobody owns, patches or retires them.

What It Does

Custom App Discovery mines the application routes and filesystem paths in your findings, compares them with the software inventory, and lists the apps that appear only there as candidates to name. Say "tag my custom app billing-portal" and he finds the matching routes and paths, shows the assets, and — once you approve — tags them Custom App : <name>.

At a glance

Key Capabilities

  • Route and path discovery — finds software by where it lives and how it's served — evidence package lists miss.
  • Gap against the inventory — keeps only what the software inventory doesn't already list.
  • Name it in plain English — "tag my custom app billing-portal" searches both routes and paths and shows the matches before anything is written.
  • Tags across both sources — Custom App : <name> on every asset with a matching path or route.
  • Ignore list — drop noise terms once, or import a list from CSV.
  • By tag — run over one tag's assets ("which custom software runs on Business Tier : Production?"): the unnamed or unowned apps on those assets, counted over just them; tagging from that view names only the tagged assets. Switch between the whole estate and your last 5 tags without re-running.

How It Works

Custom App Discovery reads the application routes and filesystem paths in your local navi.db and compares them with the software inventory. Tags go through navi's tag commands behind the write gate and a confirm. Route and path evidence depends on scan coverage.

Who It's For

Application owners who know what that mystery route is, and vulnerability management teams closing the unnamed-software gap.

Works Better With

Software Inventory covers the packaged software; Custom App Discovery covers what never got packaged. Explorer › Routes and Explorer › Paths explore the same routes and paths in depth, Exposure Routes maps them to owners, and Automation Station re-applies Custom App tags on its schedule.
