The Problem

Every team eventually needs a view nobody built: assets per owner, certificate signature algorithms, the plugins that would close the most findings. Getting it usually means a ticket, a query and a reporting tool — days for a question that should take seconds.

What It Does

Dashboard Builder turns a plain-English request into one read-only query over navi.db and renders the answer as a chart, KPI or table. 34 starter metrics run with no AI model at all. Pin what you like to your own dashboard, rearrange and resize it, email it, or promote it to a standalone page.

At a glance

Key Capabilities

  • Ask in plain English — "top 10 plugins by affected assets" — the model writes one SQL SELECT, which you can see before it renders.
  • Read-only by design — the query must be a single SELECT and navi.db is opened read-only, so nothing can be changed.
  • 34 starter metrics, no model needed — from findings by severity and VPR band to stale assets, weak-key certificates and the remediation funnel.
  • 25 chart types — KPI, bar, column, stacked, pie, donut, line, area, scatter, heatmap, Sankey, treemap, funnel, waterfall, Pareto, gauge, table and more.
  • Your dashboard — pin components, drag to reorder, size each one, switch chart type, export CSV or show the SQL; saved in your browser.
  • Share it — email the dashboard through Notify & Report, or promote it to a standalone, refreshable Custom Dashboard page.

How It Works

Dashboard Builder sends your request and navi.db's schema to the configured AI model, validates the SQL it returns, and runs it read-only against your local navi.db. Starter metrics use built-in queries. Charts render as email-safe SVG, so they look the same on screen and in an inbox.

Who It's For

Analysts with a one-off question, VM leads who want a team view without a BI project, and anyone who needs a chart for a meeting this afternoon.

Works Better With
