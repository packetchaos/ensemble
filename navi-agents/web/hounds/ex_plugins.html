EXPLORER › PLUGINS
Platform
“See every plugin in your estate — and how many assets each touches.”

The Problem

Thousands of plugins fire across an estate. Knowing which ones, in which family, on how many assets, is the starting point for any remediation plan — and it shouldn't take a query.

What It Does

Explorer › Plugins lists every distinct plugin in navi.db with its family and the number of assets it fires on, searchable by ID, name or family. Any plugin on assets can be handed to Remote Remediation for a remediation plan.

At a glance

Key Capabilities

  • Every distinct plugin — ID, name and family, with how many assets it fires on.
  • Search — by ID, name or family.
  • Open the detail — a linked row opens the plugin's full detail.
  • Fix from here — Fix sends the plugin to Remote Remediation's remediation planner, pre-filled.

How It Works

Explorer › Plugins runs a read-only search over the plugins in your local navi.db; results page on the server, 20 rows a page (up to 50).

Who It's For

Remediation planners sizing a fix, and analysts exploring what the scanner sees.

Works Better With

Part of the search pack. Dashboard Builder's "top reduction plugins" and Explorer › Plugins's asset counts point at the same fixes; Remote Remediation carries them out.
