EXPLORER › TAGS
Platform
“See every tag — and exactly which assets carry it.”

The Problem

Tags are how the Ensemble's work reaches Tenable, but once there are hundreds of categories and values, nobody can say what exists, how many assets carry each one, or whether a tag landed where it should.

What It Does

Explorer › Tags lists every tag in navi.db — one row per category : value with its asset count — searchable by category or value. Click a tag to see exactly which assets carry it, each linking to Asset Dossier and to the asset in Tenable.

At a glance

Key Capabilities

  • Every tag — one row per category : value, with its asset count and when it was first and last applied.
  • Search — by category or value.
  • Who carries it — every asset carrying the tag — host, IP, OS, ACR, AES, when it was tagged, and a Tenable link.
  • Deep-dive — every host opens Asset Dossier.
  • Email the result — send the list through Notify & Report.

How It Works

Explorer › Tags reads the tags and assets tables in your local navi.db and changes nothing. New tags appear after the next navi asset sync.

Who It's For

Anyone checking that a tag landed, auditing the tag estate, or finding the assets behind a tag.

Works Better With

Explorer › Tags reads what the tagging specialists write. Tag Removal removes what no longer belongs, and the Tagging log shows each write from the Ensemble's side.
