🧩 Plugin coverage — is every open finding owned?

Every open, non-info finding is zipped to its plugin's route and the paths that plugin was found at on that asset — 1:1 or many-to-many. A finding is owned when its asset carries an Owner tag for that route or one of those paths; decided when it carries Ignored / Accepted / Mitigated instead.

✨ Ask — describe the ownership mapping

e.g. "give all payment & billing routes to VM Team, put /opt and nginx paths under Networking Systems, assign the docker routes to Custom Apps."
Or set a disposition instead of an owner — "ignore the ICMP route, accept the OpenSSL route, all Windows Office routes are mitigated." That tags Owner : <route>: Ignored / Accepted / Mitigated so it drops off the gap list. Disposition phrases work even without a model key.
