🛡️ Protection · assets the Ensemble changed

Tagging an asset NO : UPDATE locks its ACR: navi enrich acr skips it on every later change (by any specialist, Automation Station or a script). navi reads the tag from navi.db, so protection takes effect after the next navi.db sync (navi update assets; Tenable needs ~30 min to propagate a tag) — until then a row shows pending. The tag is always written exactly NO : UPDATE, even with Settings → Test run on. To remove protection use 🗑️ Tag Removal — only Tag Removal removes tags.
